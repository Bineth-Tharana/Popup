# Popup💬

A simple and responsive Popup Modal built using HTML, CSS and JavaScript. This project demonstrates how to create an interactive popup window that can be opened and closed using user actions. The popup can be used for alerts, notifications, announcements, confirmations or displaying additional content on a webpage.

## 🚀 Features

- Responsive popup modal design
- Smooth open and close animations
- Overlay background effect
- User-friendly interface
- Lightweight and easy to customize
- Built with pure HTML,CSS and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```

Popup/
│
├── index.html

````

## 🎯 How It Works

1. Click the **Submit** button.
2. The popup modal appears with an overlay.
3. Click the **OK** button or outside the popup to dismiss it.
4. The popup smoothly disappears from the screen.

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/Bineth-Tharana/Popup.git
````

2. Navigate to the project folder:

```bash
cd Popup
```

3. Open `index.html` in your browser.
